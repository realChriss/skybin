# Development

Skybin is built with Rust, [egui](https://github.com/emilk/egui)/eframe for the UI and [rust-s3](https://github.com/durch/rust-s3) on tokio for storage access.

## Run

```sh
cargo run --release
```

## Test

```sh
cargo test                       # backend unit tests + headless UI tests (egui_kittest), offline
S3_TEST_ENDPOINT=http://127.0.0.1:9000 cargo test -- --ignored   # end-to-end against a real server
```

You can start a throwaway server for the end-to-end test with `docker run --rm -p 9000:9000 minio/minio server /data`.

## Release

Run `./release.sh` on `main`. It bumps the version in `Cargo.toml`, then tags and pushes, which builds and publishes the release.

Release builds get their version from the tag through `SKYBIN_VERSION`. Only those check for updates, so to try the update flow locally run `SKYBIN_VERSION=v0.0.1 cargo run`.

## Icon

`assets/icon.png` and `assets/icon.ico` are generated by `scripts/icon.py` (needs Pillow): `python scripts/icon.py`.

## UI icons

The UI uses [Lucide](https://lucide.dev/icons) icons from a font. `scripts/icons.py` (needs fonttools) keeps only the icons it lists in `assets/lucide.ttf` and writes their names to `src/ui/icons.rs`. To add one, add it to that list and run `python scripts/icons.py`.
